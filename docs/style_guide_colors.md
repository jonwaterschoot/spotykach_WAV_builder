# Spotykach Style Guide: App Colors

This guide lists the primary colors used across the Spotykach WAV Builder.

## Tape Colors
These are the signature colors for each tape deck.

- **Red**: `#f00f13` (Brand Red)
- **Blue**: `#4771F9`
- **Green**: `#23E073`
- **Pink**: `#f24a93`
- **Yellow**: `#ffb900`
- **Turquoise**: `#2dd4bf`

## Accent Colors
Key colors used for interactions, alerts, and highlighting.

- **Synthux Action**: `#23E073` (Primary action color)
- **Accent Orange**: `#F58B44` (Locate pulse, attention items)
- **Light Yellow**: `#FFDF9B` (Secondary highlights)

## Interface Backgrounds
The core neutral tones of the dark UI.

- **Solid Black**: `#000000` (Main app container)
- **Main Background**: `#131314` (General content area)
- **Panel Background**: `#1a1a1a` (Floating panels/cards)
- **Browser Background**: `#1b1b1b` (File browser list)
- **Tape Interface**: `#444746` (Tape selector sidebar)
