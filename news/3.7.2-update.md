# Metadata, Readability & Duplicate Sync (v3.7.2)

This release focuses on improving SD card duplicate detection, enhancing the news reader's readability, and bringing visual consistency to duplicate highlighting.

### What's new:
- **Resized News Header**: Expanded the featured news and history panel size for a much cleaner and easier-to-read dashboard when checking updates.
- **Visual Consistency in All Tapes**: Resolved a bug where duplicate/conflicting files in the All Tapes grid did not show their orange highlight borders. Now they match the Single Tape view perfectly!

### Technical Improvements:
- **Smart SD Card Duplicate Detection**: Embedded custom WAV metadata (such as UUIDs, processing details, and slice points in `ICMT` tags) directly into exported audio files. The builder now uses these tags to perform near-instant same-content checks during SD card sync, falling back to bit-for-bit SHA-256 hashing only when needed.
- **Seamless Project Restores**: Integrated automated restoration of missing local projects from SD card backups directly in the Project Manager dashboard.
- **Forced News Manifest Updates**: Integrated dynamic timestamping/cache-busting to ensure news fetch checks always retrieve the very latest updates without browser-level caching.
